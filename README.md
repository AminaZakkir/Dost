# 🎓 Dost — Your College Senior

> *"The college senior every first-generation student deserves"*

## 📌 About
Dost is an AI-powered web application that guides first-generation 
college students in India through scholarships, internships, and 
college life — available 24/7 in Malayalam, Hindi, Tamil and English.

## 🚀 Features
- 🔐 Login and Register system
- 🎓 43+ verified scholarships (Kerala, Tamil Nadu, All India)
- 💼 30+ internship opportunities (Google, Microsoft, Tata, ISRO)
- 🌐 Multilingual — Malayalam, Hindi, Tamil, English
- 📄 Resume Builder with download option
- 📊 Application History with analytics charts
- 🛡️ Admin Dashboard
- 📱 Mobile and Desktop responsive

## 🛠️ Tech Stack
- Python
- Streamlit
- Groq API (llama-3.3-70b-versatile)
- Pandas
